## `POST /api/v1/trades/{id}/buy/prepare` 🔒

**Build the unsigned escrow deposit for a buy**

Returns the simulated but unsigned `deposit_to_escrow` envelope for the authenticated buyer to sign locally. Takes no request body. Sign the returned XDR client-side, then POST it to `/api/v1/trades/{id}/buy`.

**Parameters**

| Name | In | Type | Notes |
|------|----|------|-------|
| `id` | path | string | **required** |

## `POST /api/v1/trades/{id}/confirm-delivery` 🔒

**Confirm delivery (seller only)**

Signals that the seller has delivered the airtime/data. Returns 202 immediately. Payment release runs asynchronously via the Soroban `release_payment` call with up to 3 retry attempts. Parties are notified via SSE.

**Parameters**

| Name | In | Type | Notes |
|------|----|------|-------|
| `id` | path | string | **required** |


**Responses**

**`202`** — Delivery confirmation accepted — payment release in progress.

## `POST /api/v1/trades/{id}/dispute` 🔒

**Dispute a locked trade**

Escalates a Locked trade to Disputed. Either the buyer or the seller of the trade may call this. An admin resolves the dispute via POST /api/v1/admin/trades/{id}/resolve.

**Parameters**

| Name | In | Type | Notes |
|------|----|------|-------|
| `id` | path | string | **required** |
