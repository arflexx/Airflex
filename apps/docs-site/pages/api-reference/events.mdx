Real-time Server-Sent Events stream

## `GET /api/v1/events` 🔒

**Server-Sent Events stream**

Persistent SSE connection for real-time trade status updates. Event types: `connected`, `trade_completed`, `trade_disputed`, `admin_alert`. Also available, unversioned, at `/api/events` for backwards compatibility.

**Responses**

**`200`** — SSE stream opened.

`text/event-stream` connection — see description above.

**`400`** — Malformed request syntax or invalid parameters.

```json
{
  "error": "Invalid request parameters"
}
```

**`401`** — Missing or invalid Bearer JWT.

```json
{
  "error": "Missing or invalid Authorization header"
}
```

**`429`** — Rate limit exceeded.

```json
{
  "error": "Too many requests. Please slow down."
}
```
