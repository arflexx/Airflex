OTP-based phone authentication

## `POST /api/v1/auth/request-otp` 🔒

**Request OTP**

Sends a 6-digit OTP to the provided phone number via Termii SMS. Creates a new user record on first call (upsert).

**Request body**

```json
{
  "phone": "+2348012345678"
}
```

**Responses**

**`200`** — OTP sent successfully.

```json
{
  "message": "OTP sent successfully"
}
```

**`400`** — Malformed request syntax or invalid parameters.

```json
{
  "error": "Invalid request parameters"
}
```

**`422`** — Request body failed schema validation.

```json
{
  "error": "Validation failed",
  "details": [
    {
      "field": "phone",
      "message": "Must be a valid international phone number (+234...)"
    }
  ]
}
```

**`429`** — Rate limit exceeded.

```json
{
  "error": "Too many requests. Please slow down."
}
```

**`500`** — Unexpected server error.

```json
{
  "error": "Internal server error"
}
```

**`502`** — Termii SMS service unavailable.

```json
{
  "error": "Failed to send OTP. Please try again."
}
```

## `POST /api/v1/auth/verify-otp` 🔒

**Verify OTP and obtain JWT**

Verifies the OTP against Termii. On success issues a 7-day JWT and provisions a Stellar wallet for new users.


## `POST /api/v1/auth/recover` 🔒

**Recover account with a backup code**

Redeems a single-use backup code (issue #108) and returns a short-lived one-time token that can be used to register a new phone number. 5 failed attempts from the same IP within 1 hour trigger a 429 lockout.

**Request body**

```json
{
  "phone": "+2348012345678",
  "recoveryCode": "ABCD-1234-EFGH-5678"
}
```

**Responses**

**`200`** — Code accepted — one-time recovery token issued.

## `POST /api/v1/auth/recover/change-phone` 🔒

**Register a new phone number after recovery**

Presents the one-time recovery token from POST /api/v1/auth/recover and moves the account to a new phone number. Sends an OTP to the new phone number and prompts the user to verify ownership via POST /api/v1/auth/verify-otp before a session JWT is issued.

**Request body**

```json
{
  "newPhone": "+2348098765432",
  "recoveryToken": "rec_token_sample_abc123"
}
```

**Responses**

**`200`** — Phone number updated — verification prompt returned.

```json
{
  "message": "string",
  "phone": "string",
  "requiresVerification": true
}
```

**`400`** — Malformed request syntax or invalid parameters.

```json
{
  "error": "Invalid request parameters"
```
