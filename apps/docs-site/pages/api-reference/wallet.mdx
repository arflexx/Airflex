Stellar wallet and Paystack withdrawals

## `GET /api/v1/wallet` 🔒

**Get wallet balance**

Returns the authenticated user's Stellar public key and current XLM balance fetched from Horizon. The secret key is never returned.

**Responses**

**`200`** — Wallet details.

```json
{
  "publicKey": "GABC1234...",
  "balance": "10000.0000000",
  "asset": "XLM",
  "network": "testnet"
}
```

**`400`** — Malformed request syntax or invalid parameters.

```json
{
  "error": "Invalid request parameters"
}
```

**`401`** — Missing or invalid Bearer JWT.

```json

}
```

**`404`** — The requested resource does not exist.

## `POST /api/v1/wallet/withdraw` 🔒

**Withdraw to bank account**

Initiates a withdrawal to a Nigerian bank account via Paystack.

**Parameters**

| Name | In | Type | Notes |
|------|----|------|-------|
| `Idempotency-Key` | header | string | **required** |


**Request body**

```json
{
  "accountNumber": "0123456789",
  "bankCode": "058",
  "amount": 10000
}
```

**Responses**

**`200`** — Withdrawal initiated successfully.

```json
{
  "success": true
}
```

**`400`** — Invalid input, missing or malformed Idempotency-Key, or insufficient balance.

```json
{
  "error": "Descriptive error message"
}
```

**`401`** — Missing or invalid Bearer JWT.

```json
{
  "error": "Missing or invalid Authorization header"
}
```

**`404`** — The requested resource does not exist.

```json
{
  "error": "Trade offer not found"
}
```

**`422`** — The Idempotency-Key was already used with a different request body.

```json
{
  "error": "Descriptive error message"
```

